# FlowDeck v0.3 requirements map

Scope approved from the attached v0.3 brief on 2026-08-14. This is a paper-only extension of the existing application. It does not sign or submit transactions, call Jupiter `/execute`, query Dune, or treat the current 25 closed positions as sufficient evidence for tuning.

| ID | Bias/failure being fixed | Requirement | Acceptance test | Audit evidence | UI evidence |
| -- | ------------------------ | ----------- | --------------- | -------------- | ----------- |
| OBS-01 | WebSocket gaps hide missed aircraft | Send one official `logsSubscribe` request per enabled wallet, with one address in each `mentions` filter and `processed` commitment. | One-request-per-wallet fixture. | Subscription/session rows include wallet, subscription ID and commitment. | Active/expected subscriptions. |
| OBS-02 | Disconnects silently lose transactions | Persist a per-wallet cursor; reconnect with exponential backoff plus jitter, resubscribe, and process `getSignaturesForAddress` catch-up oldest-first. | Reconnect, resubscribe, baseline and oldest-first fixtures. | `MISSED_BACKFILLED`, cursor and data-gap events. | Reconnect and backfill counts. |
| OBS-03 | Notifications are mistaken for trades | Fetch each transaction, decode balance deltas, and reject ordinary transfers before emitting a wallet signal. | Transfer-not-swap and decode-failure fixtures. | Notification, fetch and classification timestamps; `DECODE_FAILED`. | Fetch/decode failures and detection latency. |
| OBS-04 | Processed observations can later fail | Reconcile processed signatures to confirmed, failed or disappeared without erasing the original observation. | Processed-to-confirmed/failed fixtures. | Immutable confirmation-status events. | Confirmed/failed/disappeared counts. |
| OBS-05 | Duplicate delivery inflates evidence | Deduplicate globally by signature and per wallet by `signature + wallet`, across live and backfilled paths. | Duplicate suppression fixture. | Duplicate-suppressed counter. | Duplicate count. |
| OBS-06 | Provider overload causes self-inflicted gaps | Apply bounded transaction-fetch concurrency and a provider-aware token bucket; failures degrade health instead of crashing. | Rate-limit/concurrency fixture. | Retry, rate-limit and fetch-error rows. | RPC backoff state. |
| OBS-07 | Floating token deltas lose atomic precision | Parse token and SOL balances as decimal strings/`BigInt` atomic units; floats are presentation-only. | Decimal and lamport round-trip fixtures. | Atomic amounts and decimals. | Exact display amount plus units. |
| QUOTE-01 | Dexscreener marks were mislabeled executable | Label GMGN, DOM, market-cap and Dexscreener values `REFERENCE_MARK` only. | Dex source cannot produce executable quality. | Reference source/age ledger fields. | Honest price-quality badge. |
| QUOTE-02 | Fake fills ignore amount-specific routing | Require `GET https://api.jup.ag/swap/v2/order` for exact 0.01 SOL lamports; never call `/execute`. | Exact atomic request and forbidden-execute fixtures. | Quote request/response ledger. | Jupiter route health. |
| QUOTE-03 | Quote and buildability are conflated | Without taker label valid output `JUPITER_ROUTE_QUOTE`; with configured public taker and non-empty transaction label `JUPITER_BUILDABLE_ORDER`; reserve `LIVE_FILL`. | Distinct-quality fixtures. | Quality, request ID, router, mode and transaction-presence flag. | Route/buildable rates. |
| QUOTE-04 | A buy can be impossible to reverse | Immediately reverse-quote the conservative token quantity to SOL; missing reverse route becomes `NO_SELL_ROUTE`, not a position. | No-sell-route fixture. | Entry and reverse quote pair. | Sellability and no-sell-route funnel. |
| QUOTE-05 | Thin routes are valued at stale marks | Value open token atomic balance with fresh reverse quotes and drive exits from net obtainable SOL. | Reverse-quote P&L/exit fixture. | Quote age, atomic amounts, proceeds and fees. | Fresh reverse quote and route status. |
| QUOTE-06 | Quote storms and stale cache distort evidence | Single-flight identical requests, token-bucket limiting, bounded cache and configurable staleness/timeout. | Cache, timeout and stale-quote fixtures. | Latency, age, retry and error fields. | Median/p95 latency and backoff. |
| QUOTE-07 | Missing routes become invented proxy fills | `QUOTE_EXPIRED` or `NO_ENTRY_ROUTE` after the original window; market-cap ratio remains counterfactual only. | Timeout produces no fill. | Outcome cohort row with censoring. | Exact no-route/expired reason. |
| QUOTE-08 | Paper assumptions are hidden | Store quoted output, conservative filled output, minimum output when supplied and an explicit configurable haircut initially zero. | Atomic haircut fixture. | Separate quote/fill atomic columns. | Round-trip expected loss. |
| BRAIN-01 | Tiny samples and leaderboard survivorship dominate | Implement `PAPER_AGGRESSIVE_BAYES_V1` with Beta-Binomial shrinkage from unique-mint outcomes and prior ESS 20. | Two-of-two remains strongly shrunk fixture. | Posterior alpha/beta/mean/interval/version. | Probability, credible interval and evidence grade. |
| BRAIN-02 | Repeated mint rows are treated independent | Cluster historical evidence by unique mint and retain timestamps; repeated entries contribute one correlated outcome unit. | Repeated-mint fixture. | Unique-mint sample count. | Wallet posterior table. |
| BRAIN-03 | Correlated wallets multiply consensus | Build near-simultaneous common-mint wallet clusters and cap each cluster to one independent source. | Correlated-wallet fixture. | Wallet and cluster IDs/counts. | Independent-cluster count. |
| BRAIN-04 | Features leak future information | Feature values carry availability, observed timestamp and age; reject any feature timestamp later than decision time. | No-future-feature fixture. | Immutable timestamped feature map. | Missing features display unavailable. |
| BRAIN-05 | Opaque score implies false certainty | Emit TP1/final posterior, credible intervals, robust shrunk expectancy, evidence grade, positive/negative reasons, hard gate and final action. | Deterministic brain fixture. | Full brain object in decision snapshot. | Brain card. |
| BRAIN-06 | Optimising one outlier session overfits | Preserve current entry/exit behaviour as frozen `PAPER_AGGRESSIVE_CONTROL`; do not retune exits from this audit. | Config/version invariant test. | Control-policy version in manifest. | Control versus brain labels. |
| BRAIN-07 | Recovery anecdotes widen risk | Preserve stop; record `STOPPED_WATCH`; allow at most one linked re-entry after new independent evidence. | Re-entry-link fixture. | Parent position/decision ID. | Recovery/re-entry label. |
| SNAP-01 | Candidate mutation rewrites history | Deep-clone and deep-freeze a versioned snapshot before fill; later signals cannot alter it. | Post-entry mutation fixture. | Snapshot ledger with stable ID/hash. | Snapshot version/id. |
| SNAP-02 | Entry units drift between ledgers | Snapshot atomic input/output, decimals and quote quality; every fill/trade references snapshot ID. | Cross-ledger unit reconciliation fixture. | Same snapshot/decision/position IDs across ledgers. | Exact source and token balance. |
| SNAP-03 | Configuration cannot be reconstructed | Snapshot config hash, code version, thresholds, strategy and non-secret session metadata. | Hash determinism fixture. | Decision snapshot and session manifest. | Strategy/config version. |
| AUDIT-01 | Only returning aircraft enter analysis | Record immutable cohorts: universe, signal, decode/backfill, rejected, route failures, entered, open-censored, closed, unsellable and watches. | Funnel reconciliation fixture. | Outcome ledger rows. | Wald outcome funnel. |
| AUDIT-02 | Open/rejected futures are silently zero | Record fixed-horizon observations with explicit availability and censoring; unavailable is null, never zero. | Horizon/censoring fixture. | Counterfactual ledger. | Coverage/censoring. |
| AUDIT-03 | Counterfactuals contaminate trading P&L | Counterfactual rows never affect balance, equity, open count, win rate or realised P&L. | Contamination invariant fixture. | Distinct counterfactual event/ledger. | Separate actual/shadow statistics. |
| AUDIT-04 | Partial fills cannot be reconstructed | Add one fill row per entry/TP1/final/stop with atomic amounts, fees, haircut, quote ID and resulting balance. | Fill arithmetic fixture. | Fill ledger. | Ledger-reconciled totals. |
| AUDIT-05 | Quotes and decisions disappear | Add quote, decision-snapshot, outcome, fill and manifest daily ledgers with stable headers and restart dedupe. | Header/restart fixtures. | Six append-only ledger families. | CSV recording status and exports. |
| AUDIT-06 | Session gaps/configuration are invisible | Manifest records start/end, schema/strategy, hashes, RPC hostname, Jupiter availability, horizons, restarts and gaps without secrets. | Manifest/redaction fixture. | Session manifest row(s). | Session/audit health. |
| AUDIT-07 | Dashboard numbers are unverifiable | Compute robust session statistics from immutable ledgers/state and provide an automated baseline reconciliation script. | Dashboard-to-ledger fixture and current-audit reconciliation. | Reconciliation output. | Gross/cost/net, outlier and clustered metrics. |
| UI-01 | Survivors dominate the funnel | Add collapsible Wald cohort counts including universe, decode/backfill, routes, censored, unsellable and recoveries. | DOM/static ID check. | Counts derive from outcome ledger. | Wald section. |
| UI-02 | Listener gaps are hidden | Show RPC/WSS subscriptions, last age, reconnect/backfill, failures, duplicates and latency percentiles. | Snapshot/API fixture. | Observation-health counters. | Data-health section. |
| UI-03 | Route quality is unclear | Show Jupiter success/buildable/no-route rates, latency, router, quote age, round-trip loss and backoff. | Snapshot/API fixture. | Quote-health aggregates. | Jupiter-health section. |
| UI-04 | Decisions look more certain than evidence | Show action, grade, posterior intervals, expectancy, clusters, sellability, reasons and versions. | Snapshot/API fixture. | Snapshot brain fields. | Brain section. |
| UI-05 | Positions hide atomic/route state | Show exact token balance, entry and reverse quotes, quote age, net P&L, route status and unchanged exits. | Snapshot/API fixture. | Position/fill/quote linkage. | Open-position section. |
| UI-06 | Outlier dependence is hidden | Show gross, costs, net, expectancy, median, profit factor, net ex-best, best contribution, unique mints and clustered results. | Reconciliation fixture. | Trade/fill arithmetic. | Robust-statistics section. |
| TEST-01 | Financial invariants regress silently | Keep current tests and add focused deterministic mocked-network tests from the v0.3 list. | `npm test`. | Test report. | Not applicable. |
| TEST-02 | Local smoke may move funds | Paper lifecycle smoke uses mocked Jupiter only and asserts no signing, `/execute`, GMGN live process or state-directory mutation. | `npm run smoke`. | Temporary audit reconstruction. | Snapshot generated by smoke. |
| TEST-03 | Static safety scope can drift | Static check rejects `/execute`, `LIVE_FILL` assignment, secret persistence and non-BigInt atomic conversions in v0.3 modules. | `npm run check`. | Check output. | Not applicable. |
